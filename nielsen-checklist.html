產品簡介 · About 存脆 ThreadMark
一款 iOS 行動 App，把 Threads 上的「徵集串／推薦串／競賽串」變成個人知識庫。使用者透過分享選單把串文存入 App，加上自己的註解，分類到資料夾；資料夾內可以用 AI 自動歸納或對話問答，並把答案存成「卡片」回頭查閱。

評估步驟 · How to use this checklist
  1. 先看完下方 3 個 Task，了解使用者目標
  2. 實際操作 Mid-Fi Prototype 完成這 3 個 Task
  3. 逐題評估，每題：(a) 在 prototype 中找到對應位置 → (b) 圈選嚴重程度 0–4 → (c) 在 Notes 寫下你發現的具體問題
  4. 第一次評估：先看機制與流程；第二次評估：再看介面、文字、元件細節
  5. 除清單問題之外，自身發現的問題請寫在每題 Notes 或文末「其他發現」

01三個評估 Task

EASY
Task 1 · 把一則 Threads 推薦串存入 App，並分類到資料夾
情境：你在 Threads 看到一則「日本家電購買推薦」徵集串，想之後出國前回頭看。請用 App 把它存下來，加上自己的註解，並讓它出現在你建立的「日本旅遊」資料夾中。
簡單
MID
Task 2 · 把同一則串文同時收進兩個資料夾，並設定今晚提醒
情境：剛才那則日本家電購買推薦串文，你覺得它同時屬於「日本旅遊」和「家電購物」兩個主題，希望兩個資料夾都看得到。並請設定今晚8:00提醒你再看一次。
中等
HARD
Task 3 · 用 AI 整理「家電購物」資料夾，並把答案存成卡片
情境：你在「家電購物」資料夾裡已經存了 12 則串文。你想知道「2 萬內掃地機誰最常被推薦」，並把 AI 給的答案存成卡片以後查。請嘗試 AI Chat 。
複雜
